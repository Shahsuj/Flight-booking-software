# Flight-booking-software

✈️ Flight Booking System

📌 About the Project

The Flight Booking System is a Python-based application that provides a graphical user interface (GUI) for managing flight bookings. It is developed using Python Tkinter and connected to a SQL database to store and manage flight and booking information.

The project demonstrates how a desktop application can interact with a database to perform basic flight booking operations.

🚀 Features

* Graphical User Interface: Simple and user-friendly interface built using Tkinter.
* Database Connectivity: Connects to a SQL database to store and retrieve information.
* Flight Management: Supports working with flight information stored in database tables.
* Booking Management: Helps manage flight booking records.
* Data Storage: Stores relevant information in database tables for future access.

🛠️ Technologies Used

* Python – Application logic
* Tkinter – Graphical User Interface (GUI)
* SQL – Database queries and data management
* OneDatabase – Database platform used for storing project data

⚙️ Requirements

* Python 3.x
* Tkinter
* SQL database access
* Required database connection details

▶️ How to Run

1. Clone or download this repository.
2. Ensure Python is installed on your system.
3. Configure the database connection details in the Python source code.
4. Make sure the required database tables are created and accessible.
5. Install any additional Python packages required by the project.
6. Run the main Python file:

python Software.py

    Replace Software.py with the actual name of your Python file if it differs.

🗄️ Database

The application connects to a SQL database containing tables used to store and manage the project’s flight booking data.

The database connection must be configured correctly before running the application.

🎯 Project Objective

The main objective of this project is to apply Python programming, GUI development, and SQL database connectivity to build a basic flight booking application.
